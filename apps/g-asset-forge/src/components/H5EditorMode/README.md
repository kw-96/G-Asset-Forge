# H5 编辑模式组件

H5 编辑模式是 G-Asset Forge 的专用长图编辑功能，提供类似秀米的专业 H5 编辑体验。

## 组件结构

### H5EditorMode

主容器组件，管理整个 H5 编辑模式的状态和布局。

**功能特性：**

- 模式切换管理（设计模式 ↔ H5 模式）
- 内容块状态管理
- 编辑器配置适配

### H5Canvas

垂直滚动的长图画布组件，基于现有画布系统实现。

**功能特性：**

- 375px 移动端标准宽度
- 动态高度适配内容
- 内容块选择和交互
- 拖拽排序支持

### H5Toolbar

H5 专用工具栏，提供长图编辑相关功能。

**功能特性：**

- 返回设计模式
- 撤销/重做操作
- 预览模式切换
- 保存和导出功能

### ContentBlockPanel

内容块管理面板，提供预设组件和图层管理。

**功能特性：**

- 文本块、图片块、按钮块添加
- 内容块拖拽排序
- 图层管理界面
- 内容块删除操作

### MobilePreview

移动端预览组件，模拟真实设备显示效果。

**功能特性：**

- iPhone/Android 设备模拟
- 实时预览更新
- 状态栏和系统 UI 模拟
- 预览信息显示

## 使用方式

```tsx
import { H5EditorMode } from './H5EditorMode';

// 在 Editor 组件中使用
<H5EditorMode onModeSwitch={handleModeSwitch} />;
```

## 技术实现

### 数据结构

```typescript
interface ContentBlock {
  id: string;
  type: 'text' | 'image' | 'button';
  content: any;
  style: any;
}
```

### 状态管理

- 使用 React useState 管理内容块列表
- 选中状态通过 selectedBlockId 控制
- 拖拽排序通过数组索引操作实现

### 样式设计

- 采用现代化的卡片式布局
- 响应式设计，适配不同屏幕尺寸
- 统一的颜色主题和交互反馈

## 扩展计划

1. **内容块类型扩展**

   - 视频块
   - 音频块
   - 表单块
   - 分割线块

2. **高级功能**

   - 内容块模板
   - 批量操作
   - 样式复制粘贴
   - 动画效果

3. **导出增强**
   - 多种分辨率导出

   - 二维码生成
