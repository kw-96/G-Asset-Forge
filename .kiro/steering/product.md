# 产品概述

**G-Asset Forge** 是一款基于 Canvas 实现的专业图形编辑器，专为游戏资产创建和图形设计而打造。

## 核心特性

- **专业图形编辑**: 矢量图形、位图编辑、图层管理
- **游戏资产优化**: 专为游戏开发优化的工具集
- **高性能渲染**: 基于 Canvas 的高性能渲染引擎
- **跨平台支持**: Web 应用 + 桌面应用 (Electron)
- **国际化支持**: 中英文界面
- **插件系统**: 可扩展的插件架构

## 应用程序

项目包含多个应用程序：

- **g-asset-forge**: 主图形编辑器应用
- **g-asset-forge-multiplayer**: 协作多人版本
- **workbench**: 开发/测试工作台
- **backend**: NestJS API 服务器
- **docs**: VitePress 文档站点

## 目标使用场景

- **游戏开发**: 角色设计、UI 设计、图标制作
- **图形设计**: 矢量图形、插画创作、Logo 设计
- **资产管理**: 游戏资源整理、批量处理
- **原型设计**: 界面原型、交互设计

## 部署方式

- **Web 应用**: 静态文件托管、CDN 加速、云服务器部署
- **桌面应用**: Windows (.exe)、macOS (.dmg)、Linux (AppImage)
