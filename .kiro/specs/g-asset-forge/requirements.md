# 需求文档

## 项目介绍

G-Asset Forge 是一个专为企业内网环境设计的桌面应用程序，用于创建游戏运营素材。该应用集成了 Suika 高性能核心，并采用基于 Figma 设计理念的现代化 UI 界面。通过复用成熟开源项目来提高开发效率，优先考虑稳定性、性能和用户体验，适用于内网部署。

## 需求列表

### 需求 1: 资源位素材设计编辑器（设计模式）

**用户故事:** 作为游戏运营素材设计师，我希望有一个类似 Figma 的专业设计体验，以便我能够快速批量的创建和编辑大量游戏运营美术素材。

#### 验收标准 1.1

1. 当用户启动应用程序时，系统应当显示类似 Figma 的主界面，包含工具栏、图层面板、属性面板和画布区域
2. 当用户选择绘制工具时，系统应当提供矩形、圆形、线条、文本等基础图形工具
3. 当用户在画布上创建图形时，系统应当实时显示图形并支持拖拽调整大小和位置
4. 当用户选择多个对象时，系统应当支持批量操作，包括对齐、分布、组合等功能
5. 当用户修改对象属性时，系统应当实时更新画布显示，包括颜色、透明度、边框等属性
6. 当用户使用图层功能时，系统应当支持图层的创建、删除、重命名、显示/隐藏、锁定等操作
7. 当用户进行撤销/重做操作时，系统应当正确恢复到对应的历史状态

### 需求 2: 活动长图素材设计编辑器（H5 模式）

**用户故事:** 作为游戏运营素材设计师，我希望有一个类似秀米的专业 H5 编辑器体验，可以快速批量的输出大量游戏活动长图素材。

#### 验收标准 2.1

1. 当用户切换到 H5 模式时，系统应当提供适合长图设计的垂直画布布局
2. 当用户添加内容块时，系统应当提供文本块、图片块、按钮块等预设组件
3. 当用户编辑文本内容时，系统应当支持富文本编辑，包括字体、大小、颜色、对齐方式等
4. 当用户上传图片时，系统应当支持常见图片格式（PNG、JPG、GIF）并自动适配画布宽度
5. 当用户调整内容块顺序时，系统应当支持拖拽排序功能
6. 当用户预览长图时，系统应当提供实时预览功能，模拟移动端显示效果
7. 当用户导出长图时，系统应当支持多种分辨率和格式的导出选项

### 需求 3: 素材库管理

**用户故事:** 作为游戏运营素材设计师，我希望能够访问专门的游戏素材库，以便我能够快速将专业元素加载到我的设计中。

#### 验收标准 3.1

1. 当用户打开素材库面板时，系统应当显示分类清晰的素材库界面
2. 当用户浏览素材时，系统应当提供图标、背景、装饰元素、角色等分类
3. 当用户搜索素材时，系统应当支持关键词搜索和标签筛选功能
4. 当用户预览素材时，系统应当提供缩略图和详细信息显示
5. 当用户拖拽素材到画布时，系统应当自动将素材添加到当前设计中
6. 当用户上传自定义素材时，系统应当支持素材的分类存储和管理
7. 当用户删除素材时，系统应当提供确认对话框防止误删除

### 需求 4: 模板库管理

**用户故事:** 作为游戏运营素材设计师，我希望能够存在专门的素材模板库，以便我能够加载模板快速批量输出游戏运营素材和游戏活动长图素材。

#### 验收标准 4.1

1. 当用户访问模板库时，系统应当提供游戏运营和活动长图两大类模板
2. 当用户浏览模板时，系统应当显示模板预览图和基本信息
3. 当用户选择模板时，系统应当支持一键应用模板到新项目
4. 当用户修改模板内容时，系统应当保持模板的基础结构不变
5. 当用户保存自定义模板时，系统应当支持模板的命名和分类存储
6. 当用户分享模板时，系统应当支持模板的导出和导入功能
7. 当用户批量应用模板时，系统应当支持批量替换文本和图片内容

### 需求 5: 项目库管理

**用户故事:** 作为游戏运营素材设计师，我希望能够存在完善的项目库，以便我可以更好的同时进行多个设计项目。

#### 验收标准 5.1

1. 当用户创建新项目时，系统应当提供项目名称、描述和类型的设置选项
2. 当用户打开项目库时，系统应当显示所有项目的缩略图、名称和修改时间
3. 当用户同时打开多个项目文件时，系统应当使用标签页方式管理多个项目
4. 当用户在标签页间切换时，系统应当快速加载对应项目内容
5. 当用户保存项目时，系统应当自动保存项目文件到本地存储
6. 当用户搜索项目时，系统应当支持按项目名称和创建时间进行筛选
7. 当用户删除项目时，系统应当提供回收站功能，支持项目恢复

### 需求 6: 导出和输出功能

**用户故事:** 作为游戏运营素材设计师，我希望能够将完成的设计作品导出为多种格式，以便适应不同的使用场景。

#### 验收标准 6.1

1. 当用户选择导出功能时，系统应当提供 PNG、JPG、SVG、PDF 等多种格式选项
2. 当用户设置导出参数时，系统应当支持自定义分辨率、质量和尺寸设置
3. 当用户批量导出时，系统应当支持选择多个画板或图层进行批量导出
4. 当用户导出高分辨率图片时，系统应当显示导出进度并保持界面响应
5. 当用户导出完成时，系统应当提供导出文件的保存位置提示
6. 当用户导出失败时，系统应当显示明确的错误信息和解决建议
7. 当用户预览导出效果时，系统应当提供实时预览功能

### 需求 7: 性能和稳定性

**用户故事:** 作为游戏运营素材设计师，我希望应用程序能够稳定运行并保持良好的性能，以便我能够高效完成设计工作。

#### 验收标准 7.1

1. 当用户操作复杂设计时，系统应当保持 60fps 的流畅渲染性能
2. 当用户打开大型项目文件时，系统应当在 3 秒内完成加载
3. 当用户进行连续操作时，系统应当保持内存使用稳定，避免内存泄漏
4. 当用户长时间使用应用时，系统应当自动保存工作进度，防止数据丢失
5. 当系统出现异常时，应当提供错误日志记录和崩溃恢复功能
6. 当用户在内网环境使用时，系统应当支持离线模式，不依赖外网连接
7. 当用户使用不同配置的计算机时，系统应当自动适配硬件性能
